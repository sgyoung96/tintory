# 틴토리 (Tintory)

호스팅 없이 아이폰의 Scriptable에서 사용하는 개인 달력과 다이어리입니다. 테마별 일정·일기를 기록하고, 대한민국 공휴일은 한국천문연구원 특일 정보 API에서 가져와 기기 안에 저장합니다.

## 아이폰에 설치

1. [Scriptable](https://scriptable.app/)을 설치합니다.
2. Scriptable에서 새 스크립트를 만들고 [Tintory.js](Tintory.js)의 전체 내용을 붙여넣어 이름을 `Tintory`로 저장합니다.
3. 스크립트를 실행합니다. 달력 아래 **공휴일 동기화**를 누르고 공공데이터포털 **한국천문연구원 특일 정보** 서비스키를 입력합니다. 인코딩된 키와 일반 키 모두 입력할 수 있습니다.
4. 이후에는 해당 월을 열 때 마지막 성공 동기화로부터 24시간이 지났으면 자동으로 다시 확인합니다. 수동으로 새로고침할 수도 있습니다.

키를 잘못 입력했거나 갱신했다면 달력 아래 **공휴일 API 키 변경**을 누릅니다.

API 키는 Scriptable Keychain에, 일정·일기와 공휴일은 아이폰의 Scriptable 로컬 Documents/Tintory/tintory-data.json에 저장됩니다. 키와 개인 기록은 Git에 포함되지 않습니다. 로컬 파일은 기기 분실이나 앱 삭제에 대비해 별도 백업이 필요합니다.

이 앱은 Scriptable 안에서 실행됩니다. iOS 기본 캘린더에 공휴일 일정을 생성하지 않으며, 틴토리 달력에 표시합니다. 인터넷 연결은 공휴일을 새로 동기화할 때만 필요합니다. API의 공휴일 발표 시점에 따라 미래의 대체공휴일이 나중에 추가될 수 있습니다.

## 개발 확인

`node --test`로 XML 변환, 월별 동기화, 키 인코딩 동작을 확인할 수 있습니다. iPhone의 Scriptable에서 화면 동작과 실제 API 키 동기화는 별도로 확인해야 합니다.

공휴일 데이터: [공공데이터포털 한국천문연구원 특일 정보](https://www.data.go.kr/data/15012690/openapi.do)
