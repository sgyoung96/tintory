# 틴토리 (Tintory)

호스팅 없이 아이폰의 Scriptable에서 사용하는 개인 달력과 다이어리입니다. PC 브라우저와 아이폰에서 같은 HTML 화면을 사용합니다. 테마별 일정·일기를 기록하고, 대한민국 공휴일은 한국천문연구원 특일 정보 API에서 가져와 기기 안에 저장합니다.

## PC에서 디자인 미리보기

이 폴더에서 `node preview-server.js`를 실행하고 브라우저에서 **http://127.0.0.1:4173**을 엽니다. 브라우저 개발자 도구의 모바일 화면 크기를 선택하면 아이폰 폭에서 확인할 수 있습니다. HTML/CSS는 [tintory.html](tintory.html)에서 수정합니다. PC 미리보기의 샘플 기록과 수정 내용은 해당 브라우저의 저장 공간에만 남으며 아이폰 기록과 연결되지 않습니다.

## 아이폰에 설치 또는 이전 버전 업데이트

1. [Scriptable](https://scriptable.app/)을 설치합니다.
2. Scriptable에서 `Tintory` 스크립트를 만들거나 기존 `Tintory` 스크립트를 열어 [Tintory.js](Tintory.js)의 전체 내용으로 교체하고 저장합니다. 기존 일정·일기 파일은 유지됩니다.
3. 스크립트를 실행합니다. 첫 실행에는 GitHub에서 화면 파일을 받아야 하므로 인터넷 연결이 필요합니다. 이후에는 화면 파일을 아이폰에 보관해 오프라인에서도 열 수 있습니다.
4. **설정 → 공휴일 새로고침**을 누르고 공공데이터포털 **한국천문연구원 특일 정보** 서비스키를 입력합니다. 이전 버전에서 키를 등록했다면 다시 입력할 필요가 없습니다.
5. 같은 월을 다시 열 때 마지막 성공 동기화로부터 24시간이 지났으면 자동으로 확인합니다. **설정 → 공휴일 새로고침**으로 바로 갱신할 수도 있습니다.

키를 잘못 입력했거나 갱신했다면 **설정 → 공휴일 API 키 변경**을 누릅니다.

## PC에서 수정한 화면을 아이폰에 반영

`tintory.html`을 수정하고 GitHub `main` 브랜치에 올린 뒤, 아이폰에서 틴토리를 닫았다가 다시 열면 새 화면을 다운로드합니다. 다운로드에 실패해도 마지막으로 저장한 화면으로 열립니다. **설정 → 새 화면 확인**으로 다운로드만 다시 시도할 수도 있습니다. 화면 코드만 GitHub를 통해 전달하며 API 키와 개인 기록은 전송하지 않습니다.

API 키는 Scriptable Keychain에, 일정·일기와 공휴일은 아이폰의 Scriptable 로컬 Documents/Tintory/tintory-data.json에 저장됩니다. 키와 개인 기록은 Git에 포함되지 않습니다. 로컬 파일은 기기 분실이나 앱 삭제에 대비해 별도 백업이 필요합니다.

이 앱은 Scriptable 안에서 실행됩니다. iOS 기본 캘린더에 공휴일 일정을 생성하지 않으며, 틴토리 달력에 표시합니다. 인터넷 연결은 공휴일을 새로 동기화할 때만 필요합니다. API의 공휴일 발표 시점에 따라 미래의 대체공휴일이 나중에 추가될 수 있습니다.

## 개발 확인

`node --test Tintory.test.js`로 이전 버전의 공휴일 변환, 월별 동기화, 키 인코딩 동작을 확인할 수 있습니다. 이전 표 화면은 [TintoryLegacy.js](TintoryLegacy.js)에 보관합니다. iPhone의 Scriptable에서 새 WebView 브리지와 실제 API 키 동기화는 별도로 확인해야 합니다.

공휴일 데이터: [공공데이터포털 한국천문연구원 특일 정보](https://www.data.go.kr/data/15012690/openapi.do)
